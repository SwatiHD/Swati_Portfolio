# 🚀 Personal Portfolio

A modern, responsive developer portfolio built using **React**, **Tailwind CSS**, and **Framer Motion** to showcase my skills, projects, and professional experience as a Frontend / Full Stack Developer.

🔗 **Live Demo:** https://swati-hd-portfolio.netlify.app

## 📌 About

This portfolio was created to present my technical skills, development projects, and professional journey in a clean, interactive, and user-friendly way.

The website focuses on performance, responsiveness, smooth animations, and modern UI practices while maintaining clean and reusable React components.

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/yourusername/portfolio.git
```

Navigate to the project

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
